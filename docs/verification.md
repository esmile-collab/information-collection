## 当前限制

- YouTube 可能要求登录确认或限制当前 IP 的字幕请求；可切换到授权浏览器或音频 ASR。
- 小红书旧分享链接可能缺少有效参数；需要最新分享链接或用户在浏览器中完成授权。
- B 站空间批量接口可能返回 HTTP 412；停止重试，切换到公开搜索和单视频采集。
- X 的登录内容依赖用户已授权浏览器会话；Cookie 不写入工作区。
- Reddit 未登录路线适合小规模公开研究；持续批量、商业用途或受限内容需要正式授权。
- 云端 ASR 可能出现轻微非确定性，关键数字、专有名词和否定词需要回听。

## 发布前验证

每次发布至少执行：

```bash
./scripts/check-source-tools.sh all
uv run --with pyyaml python \
  /path/to/skill-creator/scripts/quick_validate.py \
  .agents/skills/<skill-name>
git diff --check
```

Skill 结构检查只证明目录、frontmatter 和基本格式合规。采集质量仍需要真实输入、原始页面或媒体回看。
